# Chessroom.online - complete website

Upload ALL files in this ZIP to your GitHub Pages published folder. Keep index.html and CNAME at its root. There is no build step.

Domain: https://chessroom.online/
Author: Chessroom
Support: iplschedule19@gmail.com

SEO includes individual titles/descriptions, static self-canonicals, Open Graph/Twitter metadata, Organization/WebSite/page/game structured data, breadcrumbs on information pages, robots.txt and sitemap.xml. All page URLs use the HTTPS apex domain. Header logo is the supplied image, optimised and served locally. Favicons and an Apple touch icon are included.

GitHub Pages: set Custom domain to chessroom.online, configure your domain DNS for GitHub Pages, and enable Enforce HTTPS when available. For www, configure its DNS and have it redirect to the apex domain. The CNAME file declares the domain; it does not configure DNS by itself.

After deployment, submit https://chessroom.online/sitemap.xml in Google Search Console. Verify HTTPS and canonical redirects, then run Lighthouse on the live site. Scores depend on live hosting, crawlability and the testing tool; no score or ranking is guaranteed.

The iOS compatibility fixes are retained. Saved games remain in browser local storage. Policies describe current features and should be updated if ads or analytics are added.

Local preview: python -m http.server 8000
Then open http://localhost:8000.
